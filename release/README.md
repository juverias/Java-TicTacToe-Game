# TicTacToe Game Releases

This folder contains executable JAR files for all three versions of the TicTacToe game.

## Available Versions

1. **Basic Version** – Simple two-player TicTacToe game.
2. **Medium-Advanced Version** – Enhanced game with additional features.
3. **Advanced Version** – Advanced implementation with additional functionality.

See the [GitHub Releases](../releases) page for downloadable builds.
